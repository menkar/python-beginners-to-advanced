# python-beginners-to-advanced

A small collection of Python example scripts that demonstrate basic to intermediate concepts for learners.

## Overview

This repository contains short, focused Python examples covering loops, operators, and conditional statements. It's intended for beginners who are progressing toward more advanced topics.

## Prerequisites

- Python 3.8 or newer

## Quick setup

Create and activate a virtual environment (recommended):

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# or Command Prompt
.venv\Scripts\activate.bat
```

There are no external dependencies required for the example scripts, so no `requirements.txt` is necessary.

## Running the examples

Run any script with the Python interpreter, for example:

```bash
python main.py
python for-loop.py
```

## Repository files

- `main.py` - Example main runner
- `for-loop.py` - Examples of `for` loops
- `loops.py` - Loop variations and examples
- `conditionalStatements.py` - `if` / `elif` / `else` examples
- `operators.py` - Operator usage examples
